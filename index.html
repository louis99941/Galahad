2. 選擇搜尋引擎

依用途分類；勾選的引擎會加入「搜尋已選引擎」。選擇會記住在目前瀏覽器。

3. 搜尋

上傳圖片後，建議優先使用真人照片搜尋。

隱私與處理

圖片預設只在瀏覽器端處理；需要提供圖片 URL 給搜尋引擎時，Worker 只將圖片暫存於 Cloudflare KV，期限約 10 分鐘。圖片上傳與刪除 API 需要登入；供搜尋引擎讀取的隨機短期圖片 URL 仍可公開讀取。
